# Data dictionary

| Column | Type | Description |
|---|---|---|
| area | numeric | Built-up area in square feet |
| bedrooms | integer | Number of bedrooms |
| bathrooms | numeric | Number of bathrooms |
| age | numeric | Property age in years |
| location | category | Neighborhood category |
| property_type | category | Apartment, Independent House, or Villa |
| price | numeric | Target price in Indian rupees |

The demo data is synthetic and generated with `scripts/generate_data.py`.
